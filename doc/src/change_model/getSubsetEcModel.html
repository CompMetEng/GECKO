getSubsetEcModel

PURPOSE

getSubsetEcModel Generate a context-specific ecModel from a general one.

SYNOPSIS

function smallEcModel = getSubsetEcModel(bigEcModel,smallGEM)

DESCRIPTION 

 getSubsetEcModel  Generate a context-specific ecModel from a general one.

 Generate a context-specific ecModel (strain/cell-line/tissue) by mapping
 reactions and genes from a conventional context-specific GEM to a general
 ecModel (bigEcModel), to yield a context-specific ecModel.

 Both models (bigEcModel and the smallGEM) should have derived from the
 same starting model. If an ecModel with human-GEM 1.15.0 is made
 (yielding the bigEcModel), then human-GEM 1.15.0 should also be the basis
 from which the context-specific GEM (smallGEM) was generated by for
 instance tINIT.

 Parameters
 ----------
 bigEcModel : struct
     enzyme-constrained version of conventional model of metabolism for a
     given species.
 smallGEM : struct
     reduced model (subset of the general model) for a specific strain
     (microbes) or cell-line/tissues (mammals).

 Returns
 -------
 smallEcModel : struct
     enzyme-constrained version of the context-specific model.

 Examples
 --------
     smallEcModel = getSubsetEcModel(bigEcModel,smallGEM);
