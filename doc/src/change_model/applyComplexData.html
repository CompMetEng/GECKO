applyComplexData

PURPOSE

applyComplexData Apply complex subunit stoichiometry to an ecModel.

SYNOPSIS

function [model, foundComplex, proposedComplex] = applyComplexData(model, varargin)

DESCRIPTION 

 applyComplexData  Apply complex subunit stoichiometry to an ecModel.

 Populates model.ec.rxnEnzMat with subunit stochiometries for protein
 complexes, based on curated data from the EMBL-EBI Complex Portal.

 Parameters
 ----------
 model : struct
     an ecModel in GECKO 3 format (with ecModel.ec structure).

 Name-Value Arguments
 --------------------
 complexInfo : struct
     structure as generated by getComplexData. If nothing is provided, an
     attempt will be made to read data/ComplexPortal.json from the
     obj.params.path folder specified in the modelAdapter.
 modelAdapter : ModelAdapter
     a loaded model adapter (default: the current default model adapter).
 verbose : logical
     true if a summary should be shown in the Command Window (default
     true).

 Returns
 -------
 model : struct
     ecModel where model.ec.rxnEnzMat is populated with subunit
     stochiometries.
 foundComplex : table
     complexes that fully matched between the model and the complex data
     (columns described under Notes).
 proposedComplex : table
     complexes where the model contained >75% but <100% of the proteins
     indicated by Complex Portal, or where the model contained more
     proteins than indicated for that complex in Complex Portal (same
     columns as foundComplex, plus a percentage match column).

 Notes
 -----
 The subunit stoichiometry is assigned per protein ID: the proteins of a
 complex need not be listed in the order of model.ec.enzymes.

 foundComplex and proposedComplex share the following columns: rxn
 (reaction identifier), complexID and name (Complex Portal identifiers),
 genes (gene names of the complex subunits), protID_model (matched protein
 IDs from the model), protID_complex (protein IDs listed by Complex
 Portal), and stochiometry (subunit stoichiometry from Complex Portal).
 proposedComplex has an additional match column with the percentage match
 between the model proteins and the proposed complex.

 Examples
 --------
     % optional arguments may be given positionally or as name-value pairs:
     [model, foundComplex, proposedComplex] = applyComplexData(ecModel, complexInfo, modelAdapter);
     [model, foundComplex, proposedComplex] = applyComplexData(ecModel, 'complexInfo', complexInfo);

 See also
 --------
 getComplexData, makeEcModel
